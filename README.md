## 🛠️ Local Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/VigneshPAlva10/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Start production server:**
   ```bash
   npm run start
   ```

## ☁️ How to Deploy on Vercel

1. Go to [https://vercel.com](https://vercel.com) and log in with your GitHub account.
2. Click **Add New Project**.
3. Import your repository (`https://github.com/VigneshPAlva10/<repo-name>`).
4. Keep the default settings (Next.js framework preset).
5. Click **Deploy**. Your site will be live on a `*.vercel.app` domain in under 60 seconds!
